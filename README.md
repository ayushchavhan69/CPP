# Object-Oriented Programming (OOP) in C++

This repository contains C++ source code implementations, exercises, and real-time applications organized by learning units.

## 📁 Repository Structure

### 1. `code book/`
Contains practice programs and conceptual C++ exercises divided into units:
- **Unit 1**: Core C++ fundamentals and introductory concepts.
- **Unit 2**: Object-oriented programming principles (Classes, Objects, Constructors, Destructors, Encapsulation).
- **Unit 3**: Advanced OOP concepts (Inheritance, Polymorphism, Abstraction, Function & Operator Overloading).

### 2. `Real-Time Applications and Live Examples/`
Contains practical projects and live application code demonstrating real-world C++ OOP use cases:
- **Unit 1**: Introductory application examples & mini-projects.
- **Unit 2**: Modular C++ application programs and mini-project code with output screenshots.
- **Unit 3**: Complex mini-projects demonstrating advanced design patterns and application logic.
